# Aperçus des projets

Captures réelles des applications lancées localement en septembre 2026, avec des données fictives. Les images sont conservées dans le format JPEG natif de la capture, sans ajout d’éléments à l’interface.

- `myfss-preview.jpg` : tableau de bord alimenté par les services application et statistiques, avec une base H2 en mémoire dédiée.
- `blazor-gamequest-preview.jpg` : session Bladebound après connexion locale, création d’une aventure et combat ; le dépôt porte le nom BlazorGameQuest.
- `hessbnb-preview.jpg` : catalogue alimenté par le service d’annonces via la gateway, avec PostgreSQL et Keycloak dédiés. Cette capture ne valide pas l’ensemble des parcours distribués.

Les instances temporaires ont été arrêtées après les captures. Les liens du CV ouvrent les images, les dépôts et leur documentation ; ils ne donnent pas accès à des instances publiques de ces trois applications.
